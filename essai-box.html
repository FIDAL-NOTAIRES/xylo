Essai d'accès aux arrêtés hébergés sur Box

Cette page teste, depuis votre navigateur, plusieurs façons d'obtenir le PDF d'un arrêté publié par le Cerema sur Box. Le serveur XYLO n'y parvient pas ; l'enjeu est de savoir si votre navigateur, lui, le peut.

Cas d'essai : arrêté termites du Mans (11/04/2024).

Prêt.
Aucun fichier n'est envoyé nulle part : tout se passe dans votre navigateur. Si un essai réussit, un lien de téléchargement apparaîtra pour contrôle.
